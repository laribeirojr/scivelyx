# SciPlot-Graphs guide

SciPlot-Graphs turns measured or simulated data into publication figures and analyses them: sheets with
formulas, more than 35 graph types in which every element can be edited, curve and peak fitting, statistics,
matrices, Python scripts and the migration of Origin, SciDAVis and QtiPlot projects.

## The window at a glance

- **Ribbon** (Home, Sheet, Matrix, Graphs, Analysis, Format, Insert, Layout) and the same commands in the menus.
- **Project** dock: sheets, matrices, graphs and folders. Double-click opens; right-click creates folders and moves items.
- **Graph tabs** in the middle, each graph with its own undo history.
- **Properties** dock: the object explorer (every element of the figure), the active panel and the series.
- **Messages** and **Notes** docks below; notes are saved in the project.

Press **F1** in the program for a short summary of the mouse and keyboard actions.
