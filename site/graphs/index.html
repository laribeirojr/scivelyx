Editing

Click anything on the figure to change it.

A test in the program guarantees that every visible part of every example figure is linked to an editable element — nothing is “just drawn”.

  • Axes in full. Linear, log, symlog and other scales; ticks by step, count or explicit positions with labels (Γ, X, M…); prefix, suffix, formula, dates and month names; breaks and secondary axes with unit conversion.
  • Text that reads like a paper. A symbol palette, Greek letters, sub- and superscripts, partial bold and italic, and Latin Modern, the font of LaTeX papers.
  • Curves and maps. Lines, symbols, error bars and bands, fills, data labels, colour maps, contours and 3D styles — down to the cap of a dash.
  • Themes and templates. Copy a format from one curve to another, save a theme and apply it to every figure of a thesis.

Analysis

Fit, find peaks, test — and keep it live.

Analyses remember how they were made. Change a value in the sheet and the fits, peak tables, filtered signals and result boxes that depend on it are redone in a chain.

01

Curve fitting

Built-in models, your own formula or a saved library; bounds, weights, Levenberg–Marquardt or Simplex; bands; global, replica and multiple linear regression fits; derived parameters.

02

Peak Analyzer

Baseline, detection, a shape per peak (Gauss, Lorentz, Voigt, pseudo-Voigt, BWF, Pearson VII) and a table of center, height, FWHM and area with uncertainties; X-ray diffraction and Raman tools.

03

Signals and statistics

Smoothing, filters, FFT, deconvolution; distribution fits, normality tests, probability plots, ANOVA with means comparisons, QC charts, outlier tests, and gadgets on the range selector.

04

Multivariate

Principal components with scree plot and biplot, k-means and hierarchical clustering with the dendrogram, ROC curves with the AUC, kernel density.

05

Time and frequency

Spectrogram, continuous wavelet transform with the cone of influence, wavelet decomposition, denoising and smoothing.

06

Errors in x, data from pictures

Orthogonal distance regression for errors in both axes; a digitizer that reads curves and symbols back from a scanned graph; HDF5, NetCDF and MATLAB files.

Migration

Bring your Origin, SciDAVis and QtiPlot projects.

Years of finished work should not stay behind. Every import and export comes with a report: what came across exactly, what approximately, and what was left out — always with the reason.

SciDAVis

.sciprj, both ways.

Sheets, matrices, notes, folders, 2D and 3D graphs, formulas and fit curves — checked against SciDAVis 2.9.2 itself.

QtiPlot

.qti, both ways.

Projects from QtiPlot 0.7 to 0.9.8, compressed ones included; SciVelyx also hands QtiPlot projects on to SciDAVis.

Origin

.opj and .opju, through Origin.

A script run inside Origin reads the project; another rebuilds a SciVelyx project inside Origin and saves .opju.

Folders

A whole archive at once.

Migrate a folder of projects in one go, from the menu or with scivelyx migrate, with one report per project.

Scripts

Python when clicking is not enough.

A script window with a console reaches the tables, matrices, fits and graphs of the open project. Scripts are saved in the project and also run without the window.

  • Run a line, a selection or everything (Ctrl+J, Ctrl+Shift+J); Ctrl+Enter evaluates and writes the value below.
  • A small, clear API: table(), new_table(), matrix(), fit(), plot(), export(), recalculate().
  • The same formulas as SciDAVis and QtiPlot in column values, including the muParser functions and c ? a : b.
  • Command line: scivelyx script analysis.py --project p.scivelyx.json in batch jobs and on clusters.

FAQ

Questions, answered plainly.

More in the FAQ of the manual.

Can SciVelyx Graphs open my Origin projects?

Yes, through Origin itself: a script run inside Origin 2021 or later reads the .opj or .opju and writes a file that SciVelyx Graphs opens, with a report of what was converted. Reading .opj files without Origin is not offered yet.

Does it replace SciDAVis and QtiPlot?

Yes. Since version 0.17 every menu action and dialog option of SciDAVis and QtiPlot has an equivalent, and SciVelyx Graphs opens and saves their project files.

What does a figure look like in the paper?

Exactly as on screen: the figure is defined in millimetres and points, and PDF, SVG and EPS keep the text editable with the fonts embedded.

Where do my data go?

Into your project file (embedded, or by reference with a checksum). The program does not upload anything and works offline.

Which language is the interface in?

English, the program's only language. The user manual and this site are in English and Portuguese.
